# UB Tunnel Pathfinder


## About the Project

Don't want to walk outside in the snow just to get to your next class? This project might help you discover UB's hidden tunnels!

UB Tunnel Pathfinder is a Python based program designed to help students navigate between buildings at the University at Buffalo's North Campus using its indoor tunnel system.

## How It Works

The program prompts users to enter their current building, followed by their desired destination.

It then uses the Breadth-First Search (BFS) algorithm to determine the shortest path between the two locations, helping students find a route while minimizing the need to walk outside.
